### ACT 3 — Self-Healing Demo (5 min) ← THIS IS THE THESIS
**Say:** "Now I'll show you the autonomous self-healing system — the core
contribution of this dissertation."

**In terminal (pre-prepared) — inject a deliberate failure:**
```bash
python3 -c "
import psycopg2
conn = psycopg2.connect('postgresql://admin:orchestrai_secret@localhost:5432/orchestrai')
cur = conn.cursor()
cur.execute('''INSERT INTO pipeline_runs
  (id, pipeline_name, dag_id, run_id, records_ingested, records_loaded,
   records_failed, status, error_message, started_at, completed_at, duration_seconds)
  VALUES (gen_random_uuid()::text, 'ingest_ecommerce',
  'ingest_ecommerce', 'demo_failure', 90, 0, 90,
  'success', 'API returned empty response', NOW(), NOW(), 45)''')
conn.commit()
print('Failure injected (records_loaded = 0)')
"
```

**Trigger healing via the API:**
```bash
curl -X POST http://localhost:8000/api/healing/trigger/ingest_ecommerce
```

**Walk through each agent in real time:**
- **Agent 1 — Monitoring:** detects `ZERO_LOAD` anomaly using rule checks + Isolation Forest
- **Agent 2 — Diagnosis:** Groq LLM analyzes lineage graph + error logs → root cause
- **Agent 3 — Fix Writer:** generates Python fix code, checks RAG cache first
- **Agent 4 — Sandbox:** executes the fix in an isolated Docker container, runs 12 tests
- **Agent 5 — Deployment:** if confidence > 75%, emails a human for approval

**In the UI:**
1. Go to the **Approval Panel** page
2. Show the pending incident card (pulsing amber border)
3. Show the root-cause text from Groq
4. Show the **12 test results** grid
5. Show the generated fix code with syntax highlighting
6. Click **Approve & Deploy**
7. Show the green **"Fix deployed"** banner

### The 10 Agents
1. **Monitoring** — rule checks + Isolation Forest anomaly detection
2. **Diagnosis** — Groq root-cause analysis over lineage + logs
3. **Fix Writer** — RAG cache → Groq → template fix generation
4. **Sandbox** — Docker-isolated 12-point test suite
5. **Deployment** — email approval + Airflow restart
6. **dbt Modeling** — star-schema proposal + SQL model generation
7. **Cost Optimizer** — EXPLAIN ANALYZE + Groq SQL rewrite
8. **Query Agent** — NL→SQL with schema awareness + chart suggestion
9. **Insights Engine** — 10 data-driven business insights
10. **Learning Agent** — ChromaDB RAG memory for fixes + queries

### Recovery / Troubleshooting
```bash
make status                       # health of all 5 services
make logs                         # tail all service logs
docker compose logs backend       # one service
docker compose restart backend    # restart a stuck service
make down && make up              # full restart
```
